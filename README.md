# Leesteve2 Portfolio

A personal portfolio website for showcasing software development work, skills, services and projects.

## Features
- Responsive portfolio layout
- Project showcase
- Services/personal branding sections
- Interactive JavaScript components
- Mobile-friendly design

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Files
- `index.html` — portfolio structure and content
- `style.css` — visual styling and responsive layout
- `script.js` — interactive behaviour

## Run Locally
Clone the repository and open `index.html` in a browser.

## Purpose
The project is designed as a professional developer portfolio and can be connected to a custom domain or GitHub Pages.
